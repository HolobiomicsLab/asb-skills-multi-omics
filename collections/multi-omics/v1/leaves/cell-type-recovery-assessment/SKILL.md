# cell-type-recovery-assessment

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmark a single-cell clustering method's ability to recover known cell types from sc_mosim-simulated scRNA-seq data by comparing cluster assignments against ground-truth simulated labels using Adjusted Rand Index and cell-type recovery tabulation.

## When to use

Use when you have simulated scRNA-seq count data with known cell-type labels (e.g., from sc_mosim/SPARSim via MOSim) and need to quantify how well a clustering tool recovers the simulated cell populations.

## When NOT to use

- Input is real experimental scRNA-seq data without ground-truth cell-type labels — ARI-based recovery assessment requires known simulated labels
- You need to simulate proteomics, metabolomics, or spatially resolved data — MOSim's single-cell simulation is restricted to scRNA-seq and scATAC-seq and operates at the count matrix level
- You only need bulk RNA-seq simulation assessment — the bulk module uses negative binomial simulation and different validation (K-means on temporal profiles, Pearson correlation), not per-cell-type clustering recovery

## Inputs

- Simulated scRNA-seq count matrix generated by sc_mosim (MOSim R package, SPARSim engine) with ground-truth cell-type labels
- Seed dataset (e.g., human pbmc.multiome 10x Genomics dataset from the SeuratData R package)
- Log(x + 1)-transformed simulated count matrix supplied to the clustering method

## Outputs

- Adjusted Rand Index (ARI) comparing predicted clusters to ground-truth cell-type labels
- Tabulation of recovered vs. merged cell types (e.g., which simulated types form separate clusters and which are combined)
- clustering_metrics.csv containing the ARI and cell-type recovery metrics

## How to apply

Generate a simulated scRNA-seq count matrix with sc_mosim from a seed dataset (e.g., the human pbmc.multiome 10x Genomics dataset from SeuratData) configured for one experimental group with a single biological replicate, which internally leverages SPARSim. Apply a log(x + 1) transformation to the simulated counts prior to clustering, as done in the MOSim methods assessment. Run the clustering tool under test (e.g., the VAE-based scDHA) on the transformed counts to embed and cluster cells. Compare predicted cluster assignments against ground-truth simulated cell-type labels by computing the Adjusted Rand Index (ARI) and tabulating which cell types are recovered versus merged (e.g., scDHA recovered five of six simulated cell types, with one cluster combining cDC and Treg cells). Write the ARI and recovery tabulation to clustering_metrics.csv and accept the result when the ARI reaches the expected benchmark (e.g., 0.949) and the expected number of cell types is identified.

## Related tools

- **MOSim** (R package whose sc_mosim function generates the simulated scRNA-seq count matrix with ground-truth cell-type labels for the clustering benchmark) — github.com/ConesaLab/MOSim
- **SPARSim** (Single-cell count data simulator internally leveraged by sc_mosim to generate the scRNA-seq matrix)
- **R** (Language in which MOSim (Bioconductor package), the log(x + 1) transformation, and the ARI computation are performed)
- **Seurat** (SeuratData package provides the pbmc.multiome 10x Genomics seed dataset used as simulation input)
- **scDHA** (VAE-based clustering method under test, applied to the log-transformed simulated counts to embed and cluster cells)

## Examples

```
devtools::install_github("ConesaLab/MOSim"); sim <- sc_mosim(omics = "scRNA-seq", scRNAseq_options = list(seedData = pbmc.multiome, minSimCost = 0.5)); log_counts <- log(counts(sim$scRNA-seq) + 1); ari <- mclust::adjustedRandIndex(scDHA_clusters, ground_truth_labels); write.csv(data.frame(ARI = ari), "clustering_metrics.csv")
```

## Evaluation signals

- ARI of 0.949 between scDHA cluster assignments and the six ground-truth simulated cell types is achieved
- Five of six simulated cell types are identified as separate clusters, with one cluster combining the cDC and Treg populations
- Simulated count matrix was produced from the human pbmc.multiome seed dataset with one experimental group and a single biological replicate
- A log(x + 1) transformation was applied to counts before clustering, matching the MOSim methods assessment protocol
- clustering_metrics.csv is written containing the ARI and cell-type recovery tabulation

## Limitations

- sc_mosim single-cell simulation is restricted to scRNA-seq and scATAC-seq only, so the benchmark cannot cover other single-cell modalities
- MOSim operates at the count matrix level rather than simulating read-level data, limiting realism for read-processing pipelines
- In the source card benchmark, one cluster combined cDC and Treg cells, showing closely related cell types may not be fully separated by the clustering method
