# deep-graph-infomax-contrastive-learning

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Self-supervised contrastive training of a graph convolutional encoder via the Deep Graph Infomax (DGI) objective as used in MCGAE: negative pairs are generated by shuffling the spot-by-gene expression matrix while keeping the spatial adjacency graph fixed, yielding modality-specific latent spot embeddings Z^X (expression view) and Z^A (adjacency view).

## When to use

Use when building self-supervised spot-level latent representations from spatial transcriptomics data where a spot-by-gene matrix and a spatial adjacency matrix are available, and you need negatives for a contrastive GCN objective without image data.

## When NOT to use

- Input data lacks spatial position information, so no spatial adjacency matrix can be constructed and the adjacency view Z^A is undefined
- Datasets with extremely large spot counts, where the O(n^2) adjacency-matrix computation may exhaust computational resources (the authors suggest subgraph sampling as a future alternative)
- A simple non-spatial expression-only baseline is required (e.g., Seurat-style linear dimensionality reduction), where a graph-contrastive encoder adds unnecessary complexity

## Inputs

- spot-by-gene expression feature matrix
- spatial adjacency matrix for the slice
- optional multi-view graph inputs chained from expression and spatial position views

## Outputs

- modality-specific latent representation Z^X (expression view, one row per spot, fixed latent dimension)
- modality-specific latent representation Z^A (adjacency view, one row per spot, fixed latent dimension)
- mcgae_spot_embeddings.csv containing both embedding matrices

## How to apply

Load the chained multi-view graph inputs: the spot-by-gene expression feature matrix and the spatial adjacency matrix for the slice. Implement the GCN encoder of Eq. 1 in PyTorch, propagating spot features through the normalized spatial adjacency. Implement the Deep Graph Infomax objective of Eq. 2 using a sigmoid-of-neighbor-average readout to obtain the graph-level summary; construct negatives by randomizing (shuffling) the gene expression profiles while keeping the network topology constant. Train until the contrastive loss converges, then extract the modality-specific latent representations Z^X (expression view) and Z^A (adjacency view), each one row per spot at a fixed latent dimension, and write both matrices to mcgae_spot_embeddings.csv.

## Examples

```
X_neg = X[torch.randperm(X.size(0), device=X.device)]  # shuffle gene expression profiles; spatial adjacency topology kept fixed as DGI negatives
```

## Evaluation signals

- Training script runs end-to-end without error on the slice's expression matrix and adjacency matrix
- Contrastive (DGI) loss decreases and converges during training on the multi-view graphs
- Output file mcgae_spot_embeddings.csv exists after the run
- Row count of the output embedding file equals the number of spots in the input slice
- The latent-dimension field is present in the output, with Z^X and Z^A each having one row per spot and a fixed latent dimension

## Limitations

- Adjacency matrix computation for spatial position information incurs O(n^2) computational complexity, which may rapidly exhaust computational resources with large sample counts
- The batch-effect handling strategy based on distance between neighboring regions may not suffice for other complex datasets
- Scalability to large-scale datasets remains an open challenge; the authors note subgraph sampling or deep multichannel GCN strategies would be needed in future
