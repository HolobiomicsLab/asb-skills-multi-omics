# tumor-type-stratified-cohort-comparison

## Summary

Evaluates the iMLGAM riskscore's predictive performance for ICB response separately within each tumor type (RCC, urothelial carcinoma, melanoma, gastric cancer, GBM) rather than only in pooled cohorts, by computing per-tumor-type ROC-AUC and comparing scores between responders and non-responders.

## When to use

Use when you have computed iMLGAM riskscores for an ICI cohort spanning multiple cancer types and need to verify the score's predictive performance holds within each individual tumor type, not just overall.

## When NOT to use

- The cohort contains only a single tumor type — there is nothing to stratify and a single pooled evaluation suffices.
- Riskscores have not yet been computed (no GA_train fit / predict output) — the stratified comparison requires the riskscore column.
- The goal is pan-cancer prospective validation in new ICB trials — the article notes the 11 RNA-seq cohorts cover only six cancer types and pan-cancer efficacy requires further prospective validation.

## Inputs

- Scored prediction matrices (trainres, validatres, testres) with riskscore and res columns from the iMLGAM pipeline
- ICI cohort outcome annotations loaded via qread('ICI cohort gene pairs.qs') with the 'res' response column
- Tumor type labels for each sample in the ICI cohort

## Outputs

- imlgam_score_evaluation_by_cancer_type.csv — per-tumor-type summary (ROC-AUC, responder vs non-responder comparison, significance)
- Per-tumor-type ROC-AUC values and Wilcoxon rank-sum p-values

## How to apply

After computing riskscores with predict(ga_fit, ...) on the training, validation, and test prediction matrices generated by basic_learner_predictor, split the scored samples by tumor type (e.g., RCC, urothelial carcinoma, melanoma, gastric cancer, GBM). For each tumor type, compute ROC-AUC against the 'res' response column and compare riskscores between responders and non-responders with a non-parametric test such as the Wilcoxon rank-sum test, using p < 0.05 as the significance threshold. The expected pattern is a consistently lower iMLGAM score in responders with ROC-AUC exceeding 0.6 in RCC, urothelial carcinoma, melanoma, and gastric cancer, while glioblastoma multiforme may show no significant responder/non-responder difference, likely due to limited sample size. Write the per-tumor-type summary (AUC, responder vs non-responder comparison, significance) to imlgam_score_evaluation_by_cancer_type.csv. This stratified check guards against a pooled-cohort AUC that is driven by between-tumor-type differences rather than true within-type predictive signal.

## Related tools

- **iMLGAM** (R package providing GA_train and predict() to compute the riskscore that is then stratified and evaluated by tumor type) — https://github.com/Yelab1994/iMLGAM
- **iMLAGA** (R package dependency that must be installed for iMLGAM's genetic-algorithm ensemble machinery) — https://github.com/Yelab1994/iMLAGA
- **qs** (Loads the ICI cohort outcome annotation file (qread) whose 'res' column is used as the response outcome for stratified comparison)

## Examples

```
testres$riskscore <- predict(ga_fit, testres); per_type <- split(testres, testres$tumor_type); lapply(per_type, function(d) c(auc=roc(d$res, d$riskscore)$auc, p=wilcox.test(riskscore~res, d)$p.value))
```

## Evaluation signals

- ROC-AUC > 0.6 within each of RCC, urothelial carcinoma, melanoma, and gastric cancer
- iMLGAM score is significantly lower in responders than non-responders (Wilcoxon rank-sum p < 0.05) for RCC, urothelial carcinoma, melanoma, and gastric cancer
- No significant responder/non-responder difference observed for glioblastoma multiforme (attributed to limited sample size)
- Output file imlgam_score_evaluation_by_cancer_type.csv contains AUC, responder comparison, and significance columns for every tumor type present in the cohort

## Limitations

- GBM showed no significant responder/non-responder difference, likely due to limited sample size, so the pattern does not hold for every tumor type
- The 11 RNA-seq cohorts analyzed cover only six cancer types; the iMLGAM score's pan-cancer predictive efficacy requires further validation through prospective ICB trials
- Some datasets lack critical clinical annotations, hindering comprehensive biomarker analyses
