# hi-c-compartment-eigenvector-decomposition

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes cis compartment (A/B) eigenvectors from Hi-C contact maps with cooltools eigs_cis, phasing E1 with an ENCODE H3K4me3 ChIP-seq track so positive values correspond to the A compartment, then compares single-cell ensemble eigenvectors to bulk eigenvectors by Spearman rank correlation.

## When to use

Use when single-cell or bulk Hi-C contact maps (cool files) must be decomposed into A/B compartment eigenvectors and quantitatively compared across conditions via eigenvector correlation.

## When NOT to use

- The analysis goal is loop calling or TAD/insulation identification rather than A/B compartment structure (this skill only addresses cis eigenvector decomposition at 500-kb resolution).
- Contact maps are not available as cool files or lack bin aggregation support for the 1-kb to 500-kb workflow described here.
- Per-single-cell compartment calls are needed with very sparse per-cell coverage — the method relies on aggregating the ensemble, and sci-L3-Hi-C captures fewer cis interactions because it uses less frequent cutters.

## Inputs

- sci-L3-Hi-C single-cell contact maps as 1-kb cool files
- bulk GM12878 Hi-C cool file from the same sci-L3 processing pipeline
- ENCODE H3K4me3 ChIP-seq signal track ENCFF818GNV (phasing track)
- hg38 (GRCh38) genome assembly bin coordinates

## Outputs

- 500-kb resolution compartment eigenvector table (E1 per genomic bin, per map and ensemble)
- compartment_correlation.tsv with Spearman correlation statistics (R, P-value)

## How to apply

Load the single-cell sci-L3-Hi-C contact maps stored as 1-kb cool files together with the bulk GM12878 Hi-C cool file generated by the same sci-L3 processing pipeline. Retrieve the ENCODE H3K4me3 ChIP-seq signal track (ENCFF818GNV) as the compartment phasing track. Run cooltools eigs_cis on each contact map, aggregating 1-kb bins to 500 kb resolution, and phase the first cis eigenvector (E1) with the H3K4me3 track so that positive values correspond to the A compartment. Aggregate the single-cell eigenvector tracks and align them to the bulk GM12878 eigenvectors by genomic bin on the hg38 assembly, then compute the Spearman rank correlation with scipy.stats.spearmanr; an ensemble-vs-bulk Spearman R of 0.87 (P < 2.2e-16) is expected for the GM12878 sci-L3-Hi-C data. Save the 500-kb eigenvector table and correlation statistics to compartment_correlation.tsv.

## Examples

```
cooltools eigs_cis -p 500000 --phasing-track ENCFF818GNV.bed contact_map.500kb.cool
```

## Evaluation signals

- Spearman correlation between sci-L3-Hi-C ensemble and bulk GM12878 compartment eigenvectors should reach R = 0.87 with P < 2.2e-16.
- Phased E1 values should be positive over H3K4me3-enriched (A compartment) bins and negative over B compartment bins, reproducing the canonical plaid A/B pattern.
- All eigenvector tracks must be aligned on identical 500-kb genomic bins of the hg38 assembly before correlation.
- Output compartment_correlation.tsv must contain both the 500-kb eigenvector table and the correlation statistics.

## Limitations

- sci-L3-Hi-C omits the ligation junction enrichment step and uses less frequent cutters than other single-cell Hi-C methods (2-4x less frequent), capturing fewer cis interactions per cell.
- Expected loss of recovered single cells with additional rounds of cell barcoding under the sci framework, due to loss of per-cell coverage.
- The pipeline repository provides no software version numbers and no changelog, so exact tool versions for cooltools/cooler are not pinned in the source context.
