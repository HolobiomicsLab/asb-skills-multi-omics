# single-cell-hic-data-aggregation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregate single-cell Hi-C contact maps (sci-L3-Hi-C cool files) into ensemble compartment eigenvectors and compare them with bulk Hi-C compartment structure, using cooltools eigs_cis at 500-kb resolution with an H3K4me3 phasing track. This skill quantifies how well single-cell-derived genome compartmentalization recapitulates bulk A/B compartments.

## When to use

Use when you have single-cell Hi-C contact maps stored as cool files plus a bulk Hi-C map from the same processing pipeline, and need to aggregate cells into ensemble compartment eigenvectors and quantify agreement with bulk compartments.

## When NOT to use

- The Hi-C data are from methods that enrich ligation junctions or use more frequent cutters — sci-L3-Hi-C omits the ligation junction enrichment step and uses less frequent cutters than other single-cell Hi-C methods, capturing fewer cis interactions, so expected compartment signal strength differs
- The contact maps are not available as cool files at 1-kb bins or cannot be aggregated to 500-kb resolution, making cooltools eigs_cis with a phasing track inapplicable
- No epigenomic phasing track (e.g. ENCODE H3K4me3) is available and compartment orientation/phasing cannot be established

## Inputs

- Ensemble of sci-L3-Hi-C single-cell contact maps stored as 1-kb cool files
- Bulk GM12878 Hi-C cool file generated by the same sci-L3 processing pipeline
- ENCODE H3K4me3 ChIP-seq signal track ENCFF818GNV (compartment phasing track)
- hg38 (GRCh38) reference genome assembly / binning

## Outputs

- 500-kb resolution compartment eigenvector (E1) table aligned by genomic bin for single-cell ensemble and bulk
- compartment_correlation.tsv containing the 500-kb eigenvector table and correlation statistics (expected Spearman R = 0.87, P < 2.2e-16)

## How to apply

Load the ensemble of sci-L3-Hi-C single-cell contact maps stored as 1-kb cool files together with the bulk GM12878 Hi-C cool file generated by the same sci-L3 processing pipeline on the hg38 (GRCh38) assembly. Retrieve the ENCODE H3K4me3 ChIP-seq signal track (ENCFF818GNV) as the compartment phasing track. Run cooltools eigs_cis on each contact map, aggregating 1-kb bins to 500 kb resolution, using the H3K4me3 track to phase the first cis eigenvector (E1) so that positive values correspond to the A compartment. Aggregate the single-cell eigenvector tracks and align them with the bulk eigenvectors by genomic bin, then compute the Spearman rank correlation with scipy.stats.spearmanr. For the sci-L3-Hi-C GM12878 ensemble, the expected result is a high correlation with bulk compartment eigenvectors (R = 0.87, P < 2.2e-16) reproducing the canonical plaid A/B compartment pattern.

## Examples

```
cooltools eigs_cis --phasing-track ENCFF818GNV.bw ensemble_1kb.cool 500000; python -c "from scipy.stats import spearmanr; print(spearmanr(scil3_e1, bulk_e1))"
```

## Evaluation signals

- Spearman rank correlation between ensemble sci-L3-Hi-C and bulk GM12878 compartment eigenvalues should reach approximately R = 0.87 with P < 2.2e-16 (scipy.stats.spearmanr)
- The phased first cis eigenvector (E1) must be oriented so positive values correspond to the A compartment, verified against the ENCODE H3K4me3 (ENCFF818GNV) phasing track
- The ensemble tracks reproduce the canonical plaid A/B compartment pattern rather than a random or anti-correlated compartment assignment
- Eigenvector tables for single-cell ensemble and bulk must be aligned by genomic bin on hg38 at 500-kb resolution (aggregated from 1-kb bins) before correlation
- compartment_correlation.tsv must contain both the 500-kb eigenvector table and the correlation statistics

## Limitations

- sci-L3-Hi-C uses less frequent cutters than other single-cell Hi-C methods (which use cutters more frequent by 2-4x), capturing fewer cis interactions and thus potentially weaker per-cell compartment signal
- sci-L3-Hi-C omits the ligation junction enrichment step, yielding a combination of whole genome sequencing (WGS) and interaction (Hi-C) data per single cell rather than pure Hi-C
- Adding additional rounds of cell barcoding under the sci framework typically reduces the number of recovered single cells due to loss of per-cell coverage, limiting the ensemble depth available for aggregation
