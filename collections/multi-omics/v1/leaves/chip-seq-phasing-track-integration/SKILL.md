# chip-seq-phasing-track-integration

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Uses a ChIP-seq signal track (ENCODE H3K4me3, ENCFF818GNV for GM12878) as a phasing track for cooltools eigs_cis compartment analysis, fixing the sign of the first cis eigenvector (E1) so positive values correspond to the A compartment, which makes sci-L3-Hi-C ensemble and bulk Hi-C eigenvectors directly comparable via Spearman correlation.

## When to use

Use when computing A/B compartment eigenvectors from Hi-C cool files whose sign must be anchored to an external chromatin mark, e.g. phasing cooltools E1 with the ENCODE H3K4me3 (ENCFF818GNV) track for GM12878.

## When NOT to use

- No cell-type-matched ChIP-seq/phasing track exists for the Hi-C sample (e.g., H3K4me3 for GM12878 on hg38) — phasing E1 against an unmatched track misassigns A/B signs.
- The question is loop calling or TAD/insulation structure rather than ~500 kb A/B compartment organization, which eigs_cis eigenvectors do not resolve.
- Input is raw sci-L3 FASTQ/BAM rather than balanced 1-kb cool contact maps — preprocess with the sciL3Pipe / 4dn-hic pipeline first.

## Inputs

- sci-L3-Hi-C single-cell contact maps stored as 1-kb resolution cool files (GM12878, hg38)
- Bulk GM12878 Hi-C cool file generated by the same sci-L3 processing pipeline
- ENCODE H3K4me3 ChIP-seq signal track (ENCFF818GNV) serving as the compartment phasing track

## Outputs

- Phased first cis eigenvector (E1) tracks at 500-kb resolution per contact map (positive values = A compartment)
- Aggregated sci-L3-Hi-C ensemble vs bulk GM12878 eigenvector table aligned by hg38 genomic bin (500 kb)
- Spearman correlation statistics (expected R = 0.87, P < 2.2e-16) and the 500-kb eigenvector table written to compartment_correlation.tsv

## How to apply

Retrieve the ENCODE H3K4me3 ChIP-seq signal track (ENCFF818GNV) for GM12878 and bin it to the same hg38 bins as the Hi-C maps, then run cooltools eigs_cis on each sci-L3-Hi-C single-cell contact map and the bulk GM12878 map, aggregating 1-kb cool bins to 500 kb resolution while passing the H3K4me3 track as the phasing track so E1 is oriented with positive values = A compartment. Phasing is essential because eigenvector signs are otherwise arbitrary per map, which would make single-cell-vs-bulk comparisons meaningless. Aggregate the phased single-cell E1 tracks into an ensemble eigenvector and align it with the bulk eigenvector by genomic bin on hg38. Compute the Spearman rank correlation between the ensemble and bulk eigenvectors with scipy.stats.spearmanr; the reference result is R = 0.87 with P < 2.2e-16, reproducing the canonical plaid A/B compartment pattern. Save the 500-kb eigenvector table and correlation statistics to compartment_correlation.tsv.

## Related tools

- **cooltools** (Runs eigs_cis on each contact map, aggregating 1-kb bins to 500 kb resolution and using the H3K4me3 track (ENCFF818GNV) to phase the first cis eigenvector (E1) so positive values = A compartment.)
- **Python** (Hosts the eigenvector aggregation, bin alignment on hg38, and writing of compartment_correlation.tsv.)
- **scipy** (scipy.stats.spearmanr computes the Spearman rank correlation between sci-L3-Hi-C ensemble and bulk GM12878 compartment eigenvectors (expected R = 0.87, P < 2.2e-16).)

## Examples

```
from scipy.stats import spearmanr; eig, bed = cooltools.eigs_cis(clr, n_eigs=3, phasing_track=h3k4me3); R, P = spearmanr(eig["E1"], bulk_E1)
```

## Evaluation signals

- Spearman R between the phased sci-L3-Hi-C ensemble E1 and bulk GM12878 E1 is approximately 0.87 (P < 2.2e-16); substantially lower R indicates sign flips, bin misalignment, or a wrong phasing track.
- Sign invariant: bins with positive E1 coincide with H3K4me3-enriched (A compartment) loci; a globally inverted plaid pattern means the H3K4me3 phasing was not applied.
- Before calling spearmanr, the ensemble and bulk eigenvector vectors have identical length and identically ordered hg38 500-kb genomic bins.
- Resolution check: eigenvectors were computed by aggregating 1-kb cool bins to 500 kb, not at native 1-kb resolution.
- compartment_correlation.tsv exists and contains both the 500-kb eigenvector table and the correlation statistics (R, P).

## Limitations

- sci-L3-Hi-C uses restriction cutters 2-4x less frequent than other single-cell Hi-C methods without ligation-junction enrichment, capturing fewer cis interactions and weakening per-cell compartment signal.
- Per-cell depth is low (the sciL3Pipe config keeps cells with cutoff: 2000 reads per single cell), so compartment eigenvectors are interpreted for the ensemble rather than individual cells.
- Phasing requires a ChIP-seq track matched to the same cell type and assembly (GM12878, hg38); the article pins no software versions (docker images are pulled from dockerhub), so cooltools behavior may vary across releases.
