# cooltools-contact-map-analysis

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes A/B compartment eigenvectors from Hi-C contact maps with cooltools eigs_cis (1-kb cool files aggregated to 500-kb resolution) and compares sci-L3-Hi-C single-cell-derived eigenvectors against bulk GM12878 Hi-C eigenvectors by Spearman rank correlation.

## When to use

Use when ensemble single-cell Hi-C contact maps (e.g. sci-L3-Hi-C cool files) must be compared to a bulk Hi-C map for A/B compartment recapitulation, or when cis eigenvectors need phasing against a histone-mark track.

## When NOT to use

- The question is per-cell or per-individual interaction structure (e.g. sister chromatid exchanges via Strand-seq) rather than ensemble A/B compartment organization.
- Input data are not contact maps / cool files (e.g. FASTQs or single-cell RNA/ATAC libraries) — those need the sciL3Pipe preprocessing pipeline first, and note sci-L3-Hi-C captures fewer cis interactions than methods using 2-4x more frequent cutters.
- The analysis targets sub-compartment (TAD/loop) resolution rather than 500-kb A/B compartment eigenvectors; this skill deliberately coarsens 1-kb bins to 500 kb.

## Inputs

- sci-L3-Hi-C single-cell contact maps stored as 1-kb cool files (hg38/GRCh38)
- bulk GM12878 Hi-C cool file processed by the same sci-L3 pipeline
- ENCODE H3K4me3 ChIP-seq signal track ENCFF818GNV (phasing track)

## Outputs

- 500-kb compartment eigenvector (E1) table for sci-L3-Hi-C ensemble and bulk GM12878, aligned by genomic bin
- Spearman correlation statistics (R = 0.87, P < 2.2e-16 expected) written to compartment_correlation.tsv

## How to apply

Load the ensemble of sci-L3-Hi-C single-cell contact maps stored as 1-kb cool files alongside a bulk GM12878 Hi-C cool file generated by the same sci-L3 processing pipeline (sciL3Pipe, hg38). Retrieve the ENCODE H3K4me3 ChIP-seq signal track ENCFF818GNV and run cooltools eigs_cis on each map, aggregating 1-kb bins to 500-kb resolution and using the H3K4me3 track to phase the first cis eigenvector (E1) so positive values denote the A compartment. Aggregate the single-cell eigenvector tracks, align them with the bulk GM12878 eigenvectors by genomic bin on hg38, and compute the Spearman rank correlation with scipy.stats.spearmanr. Expected result: Spearman R = 0.87, P < 2.2e-16, reproducing the canonical plaid A/B compartment pattern.

## Examples

```
cooltools eigs_cis --phasing-track ENCFF818GNV.bigWig --resolution 500000 sciL3_ensemble.cool 500000 > E1_500kb.tsv
```

## Evaluation signals

- Spearman rank correlation between sci-L3-Hi-C ensemble and bulk GM12878 E1 eigenvectors reaches R = 0.87 with P < 2.2e-16.
- First cis eigenvector is correctly phased: positive values coincide with H3K4me3 (A compartment) signal from ENCFF818GNV.
- The plotted eigenvalue track reproduces the canonical plaid A/B compartment pattern matching bulk GM12878.
- All eigenvectors are aligned by genomic bin at 500-kb resolution on the hg38 assembly before correlation.
- Output compartment_correlation.tsv contains both the 500-kb eigenvector table and the correlation statistics.

## Limitations

- sci-L3-Hi-C omits the ligation junction enrichment step and uses less frequent cutters than other single-cell Hi-C methods (which use cutters more frequent by 2-4x), capturing fewer cis interactions.
- The article specifies no software version numbers and pipelines are pulled as Docker/Apptainer containers from Docker Hub, so tool versions must be pinned externally.
- Inferred from the ensemble-level workflow: this skill does not assess compartment reproducibility in individual single cells, only the aggregated ensemble.
