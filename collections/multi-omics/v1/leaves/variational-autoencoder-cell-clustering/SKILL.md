# variational-autoencoder-cell-clustering

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmark a VAE-based single-cell clustering method (scDHA) on sc_mosim-simulated scRNA-seq count data, judging recovery of simulated cell types by Adjusted Rand Index. It couples MOSim/SPARSim data generation with a deep-embedding clustering evaluation.

## When to use

Use when evaluating whether a deep-learning (VAE-based) clustering tool can recover known ground-truth cell types from a simulated scRNA-seq count matrix, e.g. one replicate from one experimental group generated by sc_mosim.

## When NOT to use

- Input is raw or externally sourced single-cell data without simulated ground-truth cell-type labels — the ARI-based validation requires known simulated identities
- The goal is simulating omics beyond scRNA-seq/scATAC-seq, e.g. proteomics, metabolomics, or spatially resolved GRNs — MOSim's single-cell simulation is restricted to scRNA-seq and scATAC-seq
- Input needs read-level or read-level simulation — MOSim operates at the count matrix level rather than simulating read data

## Inputs

- scRNA-seq count matrix generated by sc_mosim (MOSim R package, SPARSim-based single-cell simulation) from one experimental group and one biological replicate
- Ground-truth simulated cell-type labels for each simulated cell
- Seed dataset: human pbmc.multiome 10x Genomics dataset from the SeuratData R package

## Outputs

- scDHA cluster assignments for each simulated cell
- Adjusted Rand Index (ARI) score comparing clusters to ground-truth labels
- Tabulation of which simulated cell types are recovered (expected: five of six, with cDC and Treg combined in one cluster)
- clustering_metrics.csv containing the clustering metrics

## How to apply

Load the human pbmc.multiome 10x Genomics seed dataset from the SeuratData R package and configure sc_mosim (MOSim R package, which internally leverages SPARSim) for one experimental group with a single biological replicate. Generate the simulated scRNA-seq count matrix, then apply a log(x + 1) transformation to the counts before embedding, as log transformation of the data is part of the MOSim assessment workflow. Run the VAE-based scDHA method on the transformed counts to embed and cluster the simulated cells. Compare cluster assignments against the ground-truth simulated cell-type labels by computing the Adjusted Rand Index and tabulating which cell types are recovered. Accept the benchmark when ARI reaches 0.949 and five of six simulated cell types are identified, writing metrics to clustering_metrics.csv.

- **MOSim** (Generates the simulated scRNA-seq count matrix used as clustering input via its sc_mosim function for one experimental group and single replicate) — github.com/ConesaLab/MOSim

## Evaluation signals

- Adjusted Rand Index reaches 0.949 when scDHA clusters are compared to ground-truth simulated cell-type labels
- Five of the six simulated cell types are identified as separate clusters
- One cluster combines the cDC and Treg populations (the expected single merge failure mode)
- The simulated count matrix was log(x + 1) transformed before clustering
- clustering_metrics.csv is written containing the ARI and cell-type recovery tabulation

## Limitations

- One simulated cell type pair (cDC and Treg) is not resolved into separate clusters by scDHA on this benchmark, capping perfect recovery
- MOSim's single-cell simulation is restricted to scRNA-seq and scATAC-seq only, as these are presently the only two commercially available sequencing techniques
- MOSim operates at the count matrix level rather than simulating read data, so clustering benchmarks see counts only
- A MOSim software version is not stated in the section, complicating exact reproducibility
