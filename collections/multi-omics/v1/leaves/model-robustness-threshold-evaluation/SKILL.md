# model-robustness-threshold-evaluation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantifies the robustness of a validated literature-derived biomolecular signaling network model (CanSeer Step 1) by perturbing input values up to 10% across 256 bootstrap network states and comparing per-cell-fate SEM of propensities against a 0.05 robustness threshold.

## When to use

Use when a literature-derived biomolecular network model must be validated as robust to small input perturbations before personalization, by measuring SEM of cell fate propensities (e.g. normal proliferation, apoptosis) across bootstrap states.

## When NOT to use

- Evaluating treatment efficacy or cytotoxic effect from cell fate outcomes of personalized, patient-annotated models — that is CanSeer's downstream dynamical-analysis-on-personalized-models step, not baseline model robustness
- The network has already been annotated with patient-specific genomic and transcriptomic data — robustness is assessed on the validated base model before patient integration

## Inputs

- Validated base biomolecular signaling network model from CanSeer Step 1 (literature-derived regulatory network)
- Base network input values subject to up-to-10% random perturbation
- Robustness threshold (SEM 0.05)

## Outputs

- Per-cell-fate SEM values for 256 perturbed network states (sem_cell_fates.csv)
- Pass/fail judgment of model robustness against the 0.05 SEM threshold

## How to apply

Load the validated base network model from the CanSeer repository (github.com/BIRL/CanSeer) built in Step 1 of the CanSeer workflow. Randomly perturb the base network input values by up to 10% to generate 256 bootstrap network states. Run dynamical analysis (DA) on each of the 256 perturbed states to obtain cell fate outcomes (normal proliferation and apoptosis). Compute the standard error of the mean (SEM) across the 256 states for each cell fate, then compare the SEMs against reported values (normal proliferation SEM 0.0025, apoptosis SEM 0.0021) and verify they fall below the 0.05 SEM robustness threshold. Write the per-cell-fate SEM values to sem_cell_fates.csv as the reproducibility artifact.

## Evaluation signals

- Computed SEM for normal proliferation reproduces the reported value of 0.0025 across 256 perturbed states
- Computed SEM for apoptosis reproduces the reported value of 0.0021 across 256 perturbed states
- All per-cell-fate SEMs fall below the 0.05 SEM robustness threshold
- Each SEM is computed from exactly 256 bootstrap network states generated by up-to-10% random input perturbation
- Output file sem_cell_fates.csv exists with one SEM value per cell fate

## Limitations

- Robustness was only assessed for two cell fates (normal proliferation and apoptosis); other fate readouts are not covered by the reported SEM values
- The perturbation scheme is limited to random input perturbations of up to 10%; conclusions do not extend to larger perturbations or structural (topology) perturbations of the network
- The 0.05 SEM robustness threshold is the article's stated criterion, not a universal standard
