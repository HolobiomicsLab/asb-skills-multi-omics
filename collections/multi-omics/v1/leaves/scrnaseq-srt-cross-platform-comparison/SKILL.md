# scrnaseq-srt-cross-platform-comparison

## Summary

Quantifies how strongly per-method accuracy scores from the 49-method benchmark (simmethods) computed on SRT reference datasets agree with scores computed on scRNA-seq reference datasets, using a paired Pearson correlation. Demonstrates whether scRNA-seq-tailored simulators transfer to spatially resolved transcriptomics (SRT) data.

## When to use

Use when a benchmark produces per-method accuracy scores computed separately on SRT and scRNA-seq reference datasets (e.g., accuracy_scores.csv) and you need to test cross-platform agreement of method rankings/scores.

## When NOT to use

- Scores are not paired per method across the two modalities (a method scored on only one platform type), since the correlation requires matched observations.
- You need accuracy rankings within a single modality (e.g., only scRNA-seq or only SRT datasets) rather than cross-platform agreement between the two.

## Inputs

- accuracy_scores.csv with per-method accuracy scores computed separately on SRT and scRNA-seq reference datasets
- Paired score columns: SRT-based scores vs scRNA-seq-based scores for the 49 simulation methods (SRTsim, scDesign3, ZINB-WaVE, scDesign2, Lun, SPARSim, scDesign3-tree, etc.)

## Outputs

- correlation_srt_scrnaseq record containing pearson_r, p-value, and number of paired methods
- Expected reference value: pearson_r approximately 0.92 as reported in Fig. 4b

## How to apply

Load the per-method accuracy score table (accuracy_scores.csv) generated by the simpipe benchmark, which evaluated 49 simulation methods on 152 reference datasets from 24 platforms. Extract the paired columns of SRT-based and scRNA-seq-based scores, then drop methods with missing values in either modality so observations are strictly paired. Compute Pearson's r and its p-value between the two score vectors with scipy.stats.pearsonr (or R cor.test), and record the number of methods contributing to the correlation. The reported result is Pearson's r = 0.92 (Fig. 4b), supporting the paper's finding that methods tailored to scRNA-seq data have potential compatibility for simulating SRT data.

## Related tools

- **simmethods** (Collection of the 49 simulation methods whose per-method accuracy scores on SRT and scRNA-seq reference datasets are correlated) — https://github.com/duohongrui/simmethods
- **simpipe** (Standard pipeline that estimates parameters from real data, simulates datasets, and evaluates simulated data, producing the accuracy scores compared across platforms) — https://github.com/duohongrui/simpipe
- **scipy.stats.pearsonr** (Computes the Pearson correlation coefficient and p-value between the paired SRT and scRNA-seq score vectors)

## Examples

```
from scipy.stats import pearsonr; r, p = pearsonr(df['accuracy_srt'].dropna(), df['accuracy_scrnaseq'].dropna())  # expect r ~ 0.92
```

## Evaluation signals

- Reproduced pearson_r ≈ 0.92 matches the value reported in Fig. 4b of the article
- The method count recorded equals the number of simulation methods with non-missing scores in both the SRT and scRNA-seq columns
- Correlation is computed only on strictly paired observations (rows with NaN in either modality are dropped)
- Correlation is symmetric: swapping the two score columns yields the same pearson_r and p-value
- p-value and pearson_r are both written to the correlation_srt_scrnaseq output, not just the coefficient

## Limitations

- The correlation only covers methods with usable accuracy scores on both SRT and scRNA-seq reference datasets; methods with execution errors (mainly failed parameter estimations or missing/infinite values in calculations) are excluded from the pairing.
- A high cross-platform correlation does not mean every method transfers: the paper stresses that some scRNA-seq-tailored methods have only 'potential compatibility' for simulating SRT data.
- Pearson's r is sensitive to outliers among the 49 methods; high scalability methods such as Phenopath, Lun, Simple, and MFA 'cannot generate realistic simulated data', which can distort score relationships.
