# graph-convolutional-encoder-implementation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Implement MCGAE's GCN encoder with Deep Graph Infomax (DGI) self-supervised contrastive training to learn modality-specific latent spot embeddings from a spot-by-gene expression matrix and a spatial adjacency matrix. Negatives in the contrastive objective are generated by shuffling gene expression profiles while keeping network topology fixed.

## When to use

Use when spatial transcriptomics data (spot-by-gene expression matrix plus a spatial adjacency matrix for a slice) must be encoded into per-spot latent representations (Z^X, Z^A) via a graph convolutional network trained with a self-supervised DGI contrastive objective.

## When NOT to use

- When the number of spots is extremely large: the adjacency-matrix computation has O(n^2) complexity, so MCGAE may rapidly exhaust computational resources (the authors suggest subgraph sampling as a future remedy, not an implemented feature here)
- When no spatial position information is available to construct the adjacency matrix, since the GCN propagation relies on the normalized spatial adjacency

## Inputs

- spot-by-gene expression feature matrix
- spatial adjacency matrix for the slice
- morphological image features (optional multi-view input for MCGAE)

## Outputs

- Z^X expression-view latent embedding matrix (one row per spot, fixed latent dimension)
- Z^A adjacency-view latent embedding matrix (one row per spot, fixed latent dimension)
- mcgae_spot_embeddings.csv containing the per-spot embeddings

## How to apply

Load the chained multi-view graph inputs: the spot-by-gene expression feature matrix and the spatial adjacency matrix for the slice. Implement the GCN encoder of Eq. 1 in PyTorch, propagating spot features through the normalized spatial adjacency. Implement the Deep Graph Infomax objective of Eq. 2 using a sigmoid-of-neighbor-average readout for the graph-level summary, with perturbed (shuffled-feature) graphs serving as negative samples while topology is held constant. Train the encoder on the multi-view graphs until the contrastive loss converges, then extract the modality-specific latent representations Z^X (expression view) and Z^A (adjacency view), each with one row per spot and a fixed latent dimension, and write them to mcgae_spot_embeddings.csv.

## Related tools

- **MCGAE** (The multi-view contrastive graph autoencoder framework whose GCN encoder (Eq. 1) and DGI contrastive objective (Eq. 2) are being re-implemented) — https://github.com/yiwen-yang/MCGAE

## Evaluation signals

- The training script runs end-to-end without error on the slice's expression matrix and spatial adjacency matrix
- The output file mcgae_spot_embeddings.csv exists and its row count equals the number of spots in the input slice
- The output includes a latent-dimension field and each embedding matrix (Z^X, Z^A) has a fixed latent dimension
- The contrastive (Deep Graph Infomax) loss converges during training on the multi-view graphs
- Negative pairs in the DGI objective are verifiably produced by shuffling gene expression profiles while the network topology remains constant

## Limitations

- Adjacency matrix computation from spatial position information incurs O(n^2) computational complexity, which may rapidly exhaust computational resources with large sample counts
- MCGAE will need to address large-scale datasets via subgraph sampling or deep multichannel GCN strategies in future work
- The batch-effect handling strategy (distance between neighboring regions) used in the 3D example may not suffice for other complex datasets
