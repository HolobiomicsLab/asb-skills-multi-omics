# figure-count-verification-against-reference

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reconstructs a package's thresholded-annotation mechanism (here, ThresholdedScatterplot/ThresholdedScatterplot_MAE from MultiModalGraphics) by re-running the documented example, extracting the upregulated/downregulated/neutral counts annotated in each rendered facet, and diffing them against counts computed independently from the same inputs.

## When to use

Use when a figure embeds computed annotations (e.g. per-facet up/down/neutral feature counts) and you must verify that independently recomputed statistics match what the package renders, or when reverse-engineering how cutoffs map to annotated classes.

## When NOT to use

- Input is a raw expression matrix and you want DE analysis performed under the hood (use ThresholdedScatterplot_table with limma/voom instead of re-verifying precomputed annotations)
- The goal is exploratory one-line plotting without count verification (MultiModalPlot() is the intended entry point)
- The figure contains no embedded statistical annotations to verify (plain ggplot2/ComplexHeatmap rendering suffices)

## Inputs

- Synthetic 1000-gene MultiAssayExperiment object generated by the vignette
- Precomputed DE table with columns log2fc, negLog10p, regulation, SampleType, timePoint
- Cutoff parameters: highLog2fc, lowLog2fc, negLog10pValue (e.g. 1.0, -1.0, 1.301)

## Outputs

- threshold_counts.csv with upregulated/downregulated/neutral feature counts per facet
- thresholded_scatterplot_mae.png faceted volcano plot with embedded per-panel count annotations
- Comparison report confirming computed vs. annotated counts agree

## How to apply

Reproduce the reference workflow end-to-end: install MultiModalGraphics from github.com/famanalytics0/MultiModalGraphics with MultiAssayExperiment, and generate the synthetic 1000-gene MAE from the knitr-rendered vignette. Apply the class's cutoff parameters — highLog2fc/lowLog2fc (e.g. |log2FC| > 1.0 flags up/down) and negLog10pValue (e.g. 1.301, i.e. p < 0.05) — which bin features into upregulated, downregulated, and neutral classes per facet. Call ThresholdedScatterplot on the DE inputs and ThresholdedScatterplot_MAE on the MAE object to render faceted volcano panels (log2 fold-change vs. –log10(p-value)) with per-panel counts. Extract the annotated counts from each panel, write them to threshold_counts.csv, and compare against independently computed counts (recompute the binning from the same cutoffs) to confirm the implementation matches the rendered output before saving the final figure as thresholded_scatterplot_mae.png.

## Examples

```
cs1 <- ThresholdedScatterplot(df_de, highLog2fc=1.0, lowLog2fc=-1.0, negLog10pValue=1.301); cs1 <- createPlot(cs1, color1="tomato", color2="grey50", color3="steelblue"); show(cs1)
```

## Evaluation signals

- Counts in threshold_counts.csv exactly match the up/down/neutral annotations printed in each rendered facet
- Annotation boundaries are consistent with the supplied cutoffs: features with log2FC > highLog2fc and –log10(p) > negLog10pValue appear in the 'up' class
- MAE-path (ThresholdedScatterplot_MAE) panels reproduce the same counts as the DE-table path for identical inputs
- Final figure thresholded_scatterplot_mae.png matches the vignette's rendered reference figure in facet structure (faceted by SampleType and timePoint) and embedded counts

## Limitations

- Vignette body may omit the example content it claims to include — verification may require reverse-engineering rather than direct visual comparison against rendered figures
- No named datasets or accession identifiers in the vignette for biological data, so reference counts only exist for the synthetic object
- Version numbers not reported in the document text (README states Version 0.99.5); behavior may drift across package versions
- A 'No Hard-Coded Numeric Flags' example shows the class can be constructed without explicit cutoffs, in which case binning defaults must be determined before counts can be recomputed
