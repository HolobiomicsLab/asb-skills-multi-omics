# fdr-power-evaluation-simulation

## Summary

A semi-synthetic benchmarking protocol that injects Gaussian-noise synthetic responses into real single-cell data (PBMC) so ground-truth conditional dependencies are known by construction, enabling empirical false discovery rate (FDR) and true positive rate (TPR) comparison of VI-VS against OLS t-test and marginal independence test baselines.

## When to use

Use when validating that a conditional independence testing method controls FDR at target levels and comparing its power (TPR) against linear/Gaussian baselines like OLS on semi-synthetic single-cell data.

## When NOT to use

- When the analysis goal is discovery on real data with unknown ground truth — this skill is a calibration/power benchmark requiring known synthetic dependencies, not a discovery workflow
- When the data are already normalized rather than raw counts — VIVS requires raw counts in the AnnData X matrix
- When evaluating a purely linear/Gaussian method on linear simulated data — the OLS baseline's miscalibration here specifically arises from violated linearity/Gaussian assumptions on real single-cell features

## Inputs

- PBMC scRNA-seq dataset (6,855 cells) as a scanpy AnnData object with raw gene expression counts
- Sampled gene set (e.g., 150 random genes) with squared log-CPM transformed features as predictors
- Number of synthetic response variables (five in the paper) generated by adding Gaussian noise
- Target FDR levels for Benjamini-Hochberg calibration (e.g., a grid of nominal levels)
- Number of Monte Carlo samples K per gene for the conditional randomization test

## Outputs

- fdr_tpr_table.csv with rows for each method (VI-VS MLP, OLS t-test, marginal independence test) and each target FDR level, containing empirical FDR and TPR columns
- Per-method calibration curves showing empirical FDR versus nominal target FDR
- Power comparison (TPR) across methods at matched FDR levels

## How to apply

Load a real scRNA-seq dataset (e.g., the 6,855-cell PBMC dataset) as a scanpy AnnData object containing raw gene expression counts, and compute squared log-CPM transformed features from a sample of 150 random genes to serve as predictors. Generate synthetic response variables y by adding Gaussian noise to selected genes so that ground-truth conditional dependencies are known by construction. Train the VI-VS model with a nonlinear MLP importance score (xy_linear=False, xy_model_kwargs={'n_hidden': 8}) on the Jax backend, run the conditional randomization test with K Monte Carlo samples per gene, and apply the Benjamini-Hochberg procedure at each target FDR level. Run the OLS t-test and a marginal independence test on the same responses, then compute empirical FDR (false discoveries / total calls) and TPR (true discoveries / total positives) per method per target level across replicates. The rationale is that only the semi-synthetic design provides known positives/negatives, so calibration (empirical FDR not exceeding the nominal target) and power can be directly measured; violations of linearity/Gaussian assumptions in baselines are expected to show as miscalibration.

## Evaluation signals

- fdr_tpr_table.csv exists and contains rows for all three methods (VI-VS, OLS t-test, marginal independence test) at all target FDR levels with FDR and TPR columns
- VI-VS empirical FDR is calibrated to (does not exceed) the nominal target FDR level across replicates
- The marginal independence test exceeds target FDR levels and OLS overestimates the FDR, consistent with the paper's expected baseline failure modes
- TPR is reported for all methods to allow power comparison at matched FDR levels
- Summary statistics are computed across the five synthetic response replicates

## Limitations

- VI-VS may not scale to many thousands of genes; genes must be filtered first (e.g., select_genes with n_top_genes=2000)
- VI-VS discoveries have no guarantees to be functional in the general case, and feedback loops, cell communication, or unobserved molecular species can lead to spurious discoveries
- OLS baseline overestimates FDR and the marginal test exceeds target FDR because real single-cell feature dependencies violate linearity/Gaussian assumptions — results are specific to nonlinear, non-Gaussian feature structures
